# Preet Desai portfolio

Hiring-officer site. **WordPress is the source of truth for editing.** `index.html` is an optional static preview on the same tokens.

Structure follows [student portfolio examples](https://www.sitebuilderreport.com/inspiration/student-portfolio-examples): About / Experience / Work / Resume / Contact.

## WordPress (edit without code)

1. Download [`wordpress/preet-desai-theme.zip`](wordpress/preet-desai-theme.zip).
2. wp-admin → Appearance → Themes → Upload Theme → activate **Preet Desai**.
3. Appearance → Editor → Templates → **Front Page**.
4. Follow **What Preet does** in [`wordpress/SOP-EDITING.md`](wordpress/SOP-EDITING.md).
5. Before sharing: [`wordpress/RECRUITING-READY.md`](wordpress/RECRUITING-READY.md).

Public URL on applications: `https://preet-desai.me`.
