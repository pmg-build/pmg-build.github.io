# Preet Desai portfolio

Hiring-officer site. **WordPress is the source of truth for editing.** `index.html` is an optional static preview that uses the same visual tokens.

## WordPress (edit without code)

1. Download [`wordpress/preet-desai-theme.zip`](wordpress/preet-desai-theme.zip).
2. wp-admin → Appearance → Themes → Upload Theme → activate **Preet Desai**.
3. Appearance → Editor → Templates → **Front Page** to edit the recruiter homepage.
4. Follow [`wordpress/SOP-EDITING.md`](wordpress/SOP-EDITING.md) for every section (hero, experience, education, achievements, projects, skills, Connect modals).
5. Before sharing with recruiters: [`wordpress/RECRUITING-READY.md`](wordpress/RECRUITING-READY.md).

Site URL for hiring officers: `https://preet-desai.me`.
